Move Capri to your Applications folder

Capri is running from the disk image or from a temporary location. Copy it to Applications so it keeps working after you eject the disk image.

Welcome to Capri

Capri is a desktop companion that runs its language model on this Mac. Setup downloads the model you choose and a small memory model, then opens Capri.

Conversations, memory and models stay in ~/Library/Application Support/Capri.
